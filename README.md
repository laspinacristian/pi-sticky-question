# pi-sticky-question

A [Pi](https://pi.dev) extension that keeps the question you are reading the answer to pinned at the top of the transcript while you scroll.

## Requirements

- Pi's fullscreen TUI: `"tuiMode": "fullscreen"` in `~/.pi/agent/settings.json`. In regular mode the extension stays inactive.

## Install

```bash
pi install git:github.com/laspinacristian/pi-sticky-question
```

It is on at startup. Toggle it with `/sticky-question`.

To update: `pi update --extensions`.

## Uninstall

```bash
pi remove git:github.com/laspinacristian/pi-sticky-question
```
